# Security Policy

## Supported Versions

Only the latest released version of Frost Client is actively supported with security fixes. Older versions should be considered unsupported — please update to the latest release before reporting an issue.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in Frost Client (for example, something that could expose account credentials, allow remote code execution, or let a malicious file/version manifest run unintended code), please report it responsibly:

- **Do not** open a public GitHub Issue for security vulnerabilities — this could expose the issue before a fix is ready.
- Instead, report it privately by emailing **[joafine@frostclient.org](mailto:joafine@frostclient.org)**, or through **[eu.frostclient.org](https://eu.frostclient.org)**.

When reporting, please include:

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce it (if possible).
- The version of Frost Client affected.
- Your operating system and any relevant environment details.

## What to Expect

- We aim to acknowledge reports within a reasonable timeframe.
- We will investigate and, if confirmed, work on a fix as a priority.
- We will keep you informed of progress and let you know once the issue is resolved.
- We ask that you give us a reasonable amount of time to address the issue before disclosing it publicly.

## Scope

This policy covers the Frost Client launcher application itself (source code, installer, and update/resource-download mechanisms). It does **not** cover:

- Vulnerabilities in Minecraft, Forge, or any third-party library/mod bundled with or downloaded by the launcher — these should be reported to their respective maintainers.
- Issues caused by running a modified or unofficial build of Frost Client not distributed through [eu.frostclient.org](https://eu.frostclient.org).

---

Thank you for helping keep Frost Client and its users safe.
